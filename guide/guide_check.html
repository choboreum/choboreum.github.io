웹 표준

마크업 유의사항

마크업 필수 규칙 지키지 않을 경우 화면이 깨져 보이거나 스크립트가 정상적으로 동작하지 못하는 등의 치명적인 오류가 발생할 수 있음

  • 한글 웹폰트 사용시 12픽셀 이하의 크기에서 글자가 흐려서 잘 보이지 않는 선명도 이슈가 발생하므로 반드시 관련부서와의 충분한 협의를 거친다.
  • DTD 선언 앞에 주석 등의 내용이 없어야 한다.
  • <head>태그의 안쪽과 <body>태그의 안쪽 이외에 내용을 삽입하지 않는다.
  • <p> 태그 안에는 <p>, <div>, <ul> 등 다른 블럭요소가 들어갈 수 없다. (display:inline 속성을 적용해도 X)
    <p> 태그는 문단을 구분하는 용도로만 사용하고 영역을 구분하는 용도로 사용하지 말 것.
  • <a> 태그 안에는 <a>태그가 들어갈 수 없다.
  • <form> 태그 안에는 <form>태그가 들어갈 수 없다.
  • <label> 태그 안에는 <label>태그가 들어갈 수 없다.
  • <pre> 태그 안에는 <img>, <object>, <big>, <small>, <sub>, <sup>태그가 들어갈 수 없다.
  • <button> 태그 안에는 <input>, <select>, <textarea>, <label>, <button>, <form>, <fieldset>, <iframe>태그가 들어갈 수 없다.
  • <button> 폼 값을 전송하는 용도로 사용하지 않을 경우 type="button"을 지정
  • 태그의 중첩에 유의
        <em><strong>내용</em></strong> (X)
    
    <em><strong>내용</strong></em> (O)
  • ID는 페이지에서 한번만 사용할 것 (스타일은 적용되나 책갈피 기능이나 스크립트를 정상적으로 사용할 수 없음)

웹접근성

주의점

  • 각 페이지를 구분할 수 있는 간단명료한 제목 제공
  • <img> 요소의 alt 속성은 반드시 제공되어야 하며, 의미없는 이미지(=단순 비주얼 요소)에 한하여 빈 값을 허용한다.
  • <img> 요소의 alt 에는 최대 100-125자를 제한으로 하되, 그 이상으로 넘어가게 된다면 sr-only class를 이용해 html태그를 사용하여 대체 텍스트를 작성한다.
  • <input> 요소는 <label>과 연결하거나 title 값을 지정하여야 한다.
  • 빈 태그 사용시에는 area-hidden="true" 속성을 사용하여 스크린리더에서 읽혀지지 않도록 처리한다.
  • 분리된 입력폼은 각각 title 값을 지정하여야 한다.
  • 적절한 <label> 텍스트 또는 title를 사용하여야 한다.
  • 적절한 태그로 작성이 어려울 경우 wai-aria를 활용하여 웹접근성을 강화할 수 있다.
  • <body> 상단에 본문 바로가기 링크를 제공하여야 한다.
  • 필요 시 tabindex를 사용하며, 키보드 탭키 이동으로 접근이 불가능한 내용이 없어야 한다.
  • 전경 콘텐츠와 배경은 4.5:1 이상의 명도 대비를 유지한다.
  • 화면을 400% 확대한 상태에서 내용과 기능에 손실이 없어야 하고, 2차원 스크롤이 발생하지 않아야 한다.
  • 자동으로 갱신되는 정보에는 '정지, 이전, 다음' 기능을 제공한다.
  • 동영상, 음성 등 멀티미디어 콘텐츠를 이해할 수 있도록 대체 수단을 제공해야 한다
  • 표에 셀 제목이 명시되지 않은 경우에도 <th> 요소를 선언하여 의미에 맞는 제목을 명시한다. (화면에 표시되지 않도록 CSS로 숨김 처리)
  • <th>에는 scope 애트리뷰트는 반드시 선언하여 현재 셀이 어느 셀의 제목인지 범위를 명시 해야 한다.
  • 탭 혹은 아코디언 UI로 인해 숨김텍스트 영역을 이용한다.

role

HTML 요소(Element)의 확장 개념으로 좀 더 명확한 HTML 요소의 구조와 의미를 부여하는 역할을 하는 속성이며, HTML 표준과의 호환성을 유지하면서 기본 동작을 무시하거나, 변경하면 안된다.

* 참고 : ARIA guide-eng, ARIA guide-ko

CSS 핵

  • CSS 핵은 엠지니와 같이 구버전 브라우저(익스플로러)로 보는 예외 케이스에만 사용한다.
  • 사용은 최소화 하되, 필요한 경우에만 사용한다.
    div{.height: 300px;}
    /* 닷핵 (.) : IE 6~7 */
  
    div{_height: 300px;}
    /* 언더스코어 핵 (_) : Win IE 4~6 */
  
    div{#height: 300px;}
    /* 해시 핵 (#) : IE 5.5~6, Mac IE 5, Opera 7, Mozilla 계열, Firefox */
  
    *html div{height: 300px;}
    /* 스타 핵 : Win IE 4~6, Mac IE 4~5 */
  
    html*div{height: 300px;}
    /* 스타7 핵 : Win IE 5.5~6, Mac IE 5, Safari */
  
    html[xmlns] div{height: 300px;}
    /* xmlns 속성 핵 : Mozilla, Firefox, Opera, Safari 등 속성 선택자를 지원하는 브라우저 */
  
    :root div{height: 300px;}
    /* root 가상클래스 핵 : Mozilla, Firefox, Mac IE 5, Safari 등 가상클래스를 지원하는 브라우저 */
  
    div{height/* \**/: 300px;}
    /* IE 8에서만 적용 : IE 8 */
  
    div{height: 300px\;}
    /* IE 8을 포함한 IE버젼에서만 적용하기 : Only IE */
  
    *+html body div{height: 300px;}
    /* IE 7, Opera 적용하기 : IE 7, Opera 8 이후 버전 */
  
    div{height/**/: 300px;}
    /* IE 6 제외시키기 : Win용 IE 6에서는 적용 제외 */
  
    html>body div{height: 300px;}
    /* IE 7, IE 8에 적용하기 : IE 7, IE 8에서만 적용 */
  
    @-moz-document url-prefix(){div}
    /* 파이어폭스만 적용 */
  
    @media screen and(-webkit-min-device-pixel-ratio:0){div}
    /* 크롬만 적용 */

SEO(검색 엔진 최적화)

참고 : 구글 검색엔진 최적화 방법

head

  <head>
    <title>CHOBOREUM</title>
    <meta property="og:type" content="website" />
    <meta property="og:title" content="CHOBOREUM" /> <!-- 사이트명 -->
    <meta property="og:description" content="퍼블리싱 가이드드" /> <!-- 사이트에 대한 설명 -->
    <meta property="og:keywords" content="정보통신업, 응용 소프트웨어 개발 및 공급업, 제조업, 컴퓨터 제조업" /> <!-- 사이트에 대한 키워드 -->
    <meta property="og:image" content="./images/layout/logo.png" /> <!-- 사이트 로고 이미지 경로 -->
    <meta property="og:url" content="" /> <!-- [DEV] content 값에 운영서버의 메인페이지 URL 표기 부탁드립니다. -->
    ...
  </head>

keywords

  <meta name="keywords" content="" />
  • 페이지 키워드를 기재/콤마(,)로 구별하여 기술/동의어와 유의어를 포함.

description

<meta name="description" content="" />
  • 페이지 정보 요약
  • 구글검색에서, 결과 페이지 내용 미리보기로 사용할 수도 있음.

title / header

  • 각각의 페이지마다 고유한 title 제공. 필요 시 헤딩 태그의 활용
  • 가능한 header의 로고는 단순 링크 <a> 태그 활용, 페이지 타이틀을 <h1>으로 정의 : 검색 우선 순위를 위함
