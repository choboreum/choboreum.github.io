코드 작성

단위

  • PC : px
  • Mobile : px / 모바일의 경우 sp환경도 고려하여 작업한다.
    • DP(Density-Independent Pixels): UI 레이아웃을 정의할 때 레이아웃 치수나 위치를 지정하기 위해 사용하는 단위이다. 픽셀 독립 단위이며 화면의 크기가 달라도 동일한 비율로 보여주기 위해 안드로이드에서 정의한 단위이며 큰 화면, 작은 화면에 상관없이 같은 크기로 나타난다.
    • SP(Scale-Independent Pixels): UI 레이아웃을 정의할 때 텍스트의 크기를 지정하기 위해 사용하는 단위이다. 화면 비율 혹은 폰트 비율을 키울 경우 비율에 따라 레이아웃이 변화된다.

  • 2줄 이상의 스타일이 수정/삭제 되었을 경우 선택자의 위 부분에 시작(/* 시작 */)주석과 선택자의 아래 부분에 끝(/* //끝 */)주석을 작성한다.
  • 1줄의 스타일이 수정/삭제 되었을 경우, 선택자의 제일 오른쪽 끝에 한줄의 주석을 작성한다.
  • CSS 주석 처리는 시작 주석을 작성하며 끝 주석은 작성하지 않는다.(2줄 이상의 수정/삭제의 경우에만 끝 주석 코드 작성) 마지막 종료 코드 이후에 오는 요소에 한 칸 띄어 쓰기를 허용한다.
  • 객체를 구분하기 위하여 코드 그룹 간 1줄의 빈 줄을 허용한다. 빈 줄의 1줄을 초과하지 않는다.
    /* title */
    .title-type1{margin: 30px 0 10px 0;}

    /* description */
    .desc{padding: 30px 24px; font-size: 18px;}

  • 폰트의 선언, filter, content에 작은 따옴표('')를 사용한다.
  • 단, url 데이터 타입에는 작은 따옴표를 사용하지 않는다.
  • 단, url 데이터 타입에는 작은 따옴표를 사용하지 않는다.
  • @charset 선언 시에는 속성 값을 큰따옴표(" ")로 감싼다.
  • background url 속성 값을 큰따옴표(" ")로 감싼다.

세미콜론(;)

마지막 선언된 속성에도 세미콜론(;)을 사용한다.

    /* 잘못된 예 */
    .class-name{margin-left: 0}

    /* 올바른 예 */
    .class-name{margin-left: 0;}

공백의 사용

  • 선택자 간, 중괄호간 한칸의 공백은 사용하지 않는다.
  • 속성 선언시 콜론 (:) 뒤에 한칸의 공백을 사용한다.
  • 중괄호 안쪽 좌우에는 공백은 사용하지 않는다.

선언 타입

CSS 선언 타입은 크게 세 가지로 분류하며, 용도에 맞게 사용한다.

링크 타입(External type)

CSS를 선언하는 가장 기본적인 방식으로, CSS 파일이 별도로 존재하는 형태이다. link 요소를 통해 HTML과 CSS 파일을 연결한다.

    <link rel="stylesheet" type="text/css" href="../css/common.css">

내장 타입(Internal type)

HTML 파일의 head 안에 스타일을 선언하는 방식으로, 프로젝트에서는 사용하지 않는다.

    <head>
    <style>
    .class-name{border: 1px solid #ccc;}
    </style>
    </head>

인라인 타입(Inline type)

HTML의 개별 요소에 style 속성을 이용하여 스타일을 선언하는 방식으로, 속성 값이 동적으로 변경되어야 하는 경우 사용한다. 속성 값에 사용되는 %와 같은 특수기호는 Character entity references로 변환하지 않는다. 이벤트를 위한 특수한 경우, display: none/block 외 사용하지 않는다.

    <div style="top: 0; left:50%;">
    …
    </div>

속성의 축약 속성 사용

CSS 최적화를 위해 속성값을 축약 한다. 단, 모든 값을 축약 할 필요는 없다. 축약을 과도하게 사용할 경우, 불필요한 재정의와 의도하지 않는 코드가 발생 할 수 있다.

축약 전 축약 후 설명
#ffffff #fff
top: 0px top: 0 속성의 값이 0일 경우 단위를 표시하지 않는다.
top: 0.1rem top: .1rem 소수점 단위에서 0이 앞에 위치하는 경우에는 0을 표기하지 않는다.
margin: 15px 15px 15px 15px margin: 15px 속성의 값이 동일한 경우 top, right, bottom, left 순서대로 축약한다.

margin: 0px 0px 30px 0px margin-bottom: 30px 불필요한 재정의를 줄이기 위해 축약 사용 보다는 margin-bottom 속성을 사용한다.

Background 약식 속성

  • 배경 이미지의 속성의 초기 선언시 반드시 background 단일 속성을 사용하며, 이후 배경적인 부분의 속성이 변경될 경우 background 관련 속성을 사용하여 제 선언 한다.
  • 선언 순서는 background-color, background-image, background-repeat, background-position, background-size, background-attachment, background-origin, background-clip 이다.
    .class-name .bg-position-type1{background-position: left center;}
    .class-name .bg-position-type2{background-position: 50%;} //필요 시 위치값을 숫자로 표기 할 수도 있다. 
    .class-name .bg-size{background-size: cover;}

    .class-name{background: url() no-repeat center / 100%;}

Border 약식 속성

  • 테두리의 스타일이 동일할 경우 반드시 border 단일 속성을 사용하고 동일하지 않을 경우 부분적 border 속성을 사용할 수 있다.
  • 속성의 값의 선언 순서는 border-width, border-style, border-color의 순서이다.
    .class-name .border-color{border-color: #ffff00;}
    .class-name .border-top{border-top: 2px solid #000;}
    .class-name .border-left-width{border-left-width: 0;}

    .class-name{border: 1px solid #ccc;}

Font 약식 속성

  • 폰트 스타일은 부모의 속성 값을 상속받기 때문에 재정의 하지 않으면 스타일이 변환되거나, 불필요한 재정의를 선언해주어야 하기 때문에 약식 속성으로 선언하지 않는다.
  • 속성의 선언순서는 font-family, font-style, font-weight, font-size, line-height 이다.
    .class-name .font-family{font-family: 'dotum';}
    .class-name .font-color{font-color: #000;}
    .class-name .font-size{font-size: 16px;}

    .class-name{font-family: 'dotum'; font-color: #000; font-size: 16px;}

z-index

z-index 속성의 속성 값의 범위는 최소 10, 최고 1000이며, 10 단위로 증감한다. 단, 10 단위 사이의 예외 변수가 발생하면 1 단위 값을 지정할 수 있다.

미디어쿼리

다른 화면 크기에 반응하는 레이아웃을 생성하는 데 사용되며, CSS 파일의 가장 아랫부분에 선언한다.

뷰포트 분기점

규칙으로 나뉘어 놓은 사이즈는 없으나 너무 많은 화면 사이즈로 구분해놓으면 운영 시 불편함이 생길 수 있기에 아래 분기점을 가이드로 지정한다.

    /* Desktop */
    @media screen and (min-width: 1024px) {
        //스타일 입력
    }

    /* Tablet */
    @media screen and (min-width: 786px) and (max-width: 1023px) {
        //스타일 입력
    }

    /* Mobile */
    @media screen and (max-width: 767px) {
        //스타일 입력
    }
    @media screen and (max-width: 575px) {
        //스타일 입력
    } 
    @media screen and (max-width: 480px) {
        //스타일 입력
    } 
    @media screen and (min-width: 320px) and (max-width: 360px) {
        //스타일 입력
    }

공통 선택자

  • 공통 선택자(*)는 웹페이지의 성능 저하를 가져오므로 가급적 사용하지 않는다.
  • 태그는 언제든지 다른 태그로 변경될 수 있으므로 태그 선택자로 스타일을 작성하지 않는다.
  • !important는 불가피한 상황을 제외하고는 사용하지 않는다.
  • 인라인 스타일의 우선 순위가 높으므로 인라인 스타일의 사용은 최소한으로 한다.
  • 선택자를 다수 작성할수록 우선 순위가 높아지므로 선택자는 가능하다면 최소 단위 / 루트 단위로 진행한다.
  • 클래스명이 자주 쓰이는 명칭일 경우 선택자를 하나, 두 개 정도 추가 작성한다.
