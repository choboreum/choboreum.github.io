선택자

  • 선택자에 직접적인 태그의 사용은 자제 하도록 하며, 되도록 class로 작성하고 예외의 경우 id로 작성한다.

코드 작성

세미콜론(;)

자바스크립트의 기본 규칙은 세미콜론을 붙이는 것, 따라서 구문 구분 시 대부분 마지막에 세미콜론을 작성하는 것을 권유한다.

들여쓰기 / 빈줄

    /* 잘못된 예 */
    <script>
    $(function(){
    $('.toggle-btn').('click', function(){alert('toggle');})
    $('.popup-btn').('click', function(){alert('popup');})
    })
    </script>
        
    /* 올바른 예 */
    <script>
    $(function(){
        $('.toggle-btn').('click', function(){
            alert('toggle');
        })

        $('.popup-btn').('click', function(){
            alert('popup');
        })
    })
    </script>
  • html, css와 동일하게 가독성을 위해 들여쓰기 규칙을 준수한다.
  • 선택자와 함수를 구분하기 위하여 그룹 간 1줄의 빈 줄을 허용한다. 빈 줄의 1줄을 초과하지 않는다.

주석

    <!-- [DEV] : 241216 | 스크립트 추가 -->
    <script>
    $(function(){
        
    })
    </script>
    <!-- //[DEV] : 241216 | 스크립트 추가 -->
  • 주석 기호와 내용 사이에 한 칸의 공백을 둔다
  • 주석은 "수정/삭제일자 | 코멘트" 순으로 작성한다.
  • 2줄 이상의 스타일이 수정/삭제 되었을 경우 선택자의 위 부분에 시작(<-- 시작 -->)주석과 선택자의 아래 부분에 끝(<-- //끝 -->)주석을 작성한다.

따옴표 사용 범위

  • js 작성 시 기본적으로 작은 따옴표('')를 사용한다.
  • 단, 이중으로 따옴표를 작성할 경우에만 큰따옴표(" ")를 작성 후 작은 따옴표('')로 감싼다.
    <script>
    for(var i = 0; i < total; i++){
        target.append('<button type="button" onclick="popup('+i+')">'+(i+1)+'</button>');
    }
    </script>
